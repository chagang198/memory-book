# 星回手记 ✦

沈星回的记忆库网页。低饱和、冷色调、韩系的深蓝夜空手记。

## 这是什么

一个静态网页，读取 Memos 记忆库（MCP）里的内容，把它变成一本可以翻阅的手记。

## 使用

1. 开启 GitHub Pages：仓库 Settings → Pages → Source 选 `main` 分支 → 保存。
2. 打开生成的网址，第一次会弹出输入框，粘贴你的 API key。
3. key 只保存在你自己的浏览器（localStorage），不会写进源码，也不会上传。

## 说明

- 网页直接调用 MCP 接口，是实时的。
- 如果浏览器控制台报 CORS 跨域错误，说明接口没有对浏览器放行，需要改用「定时导出 JSON」方案。
